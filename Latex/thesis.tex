% ABSTRACT
\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}
The aim of this work is to develop an application that leverages computer vision to analyze football match footage and extract comprehensive statistics about the players and the match overall. This project involves implementing a computer vision model to accurately identify and track key components in the footage, including players, balls, goalposts, and referees. With these components recognized, the next focus will be on computing detailed match statistics and relevant metrics. The main objective is to provide valuable insights into football matches, enhancing both player performance analysis and game strategy evaluation. To achieve proper analysis, the DFL - Bundesliga Data Shootout dataset will be used, which consists of 460, 30 second videos in mp4 format from various football matches. The implementation will be carried out in Python, with the use of OpenCV, YOLO and Roboflow.

\section{Vocabulary}
\textbf{You Only Look Once (YOLO)} - Real-time object detection algorithm that frames detection as a single regression problem, predicting bounding boxes and class probabilities directly from full images. YOLO is known for its speed and accuracy, making it a popular choice for object detection tasks \cite{Yolo}.

\vspace{1em}

\noindent \textbf{Computer Vision (CV)} - The study of digital
image structures and patterns, which is a layer of image analysis above that of
image processing and photonics. Computer vision includes image processing and
photonics in its bag of tricks in its pursuit of image geometry and image region
patterns \cite{Peters2017}.

\vspace{1em}

\noindent \textbf{Deep Learning} - sub-field of machine learning that involves the use of large neural networks to create models which are able to make accurate data-driven decisions. Suitable for creating models based on complex and substantial in size datasets. As such deep learning models are widely used in modern technologies like smartphones and self-driving cars as well as healthcare
\cite{Kelleher2019}.

\vspace{1em}

\noindent \textbf{Convolutional Neural Network (CNN)} - type of neural network designed to process grid-like data, such as images. It uses the mathematical operation convolution to automatically detect features like edges and textures. This makes CNNs highly effective for tasks like image recognition by preserving spatial relationships between pixels. They have been widely successful in computer vision applications \cite{Ian GoodfellowDeepLearning}.

\vspace{1em}

\noindent \textbf{OpenCV} - Open-source computer vision library designed for real-time applications. It provides a wide range of tools for image processing, including object detection, image recognition, and image segmentation. OpenCV is written in C and C++ and has bindings for Python, making it a popular choice for computer vision projects \cite{OpenCV}.

\vspace{1em}

\noindent \textbf{Roboflow} - Tool that simplifies the process of training computer vision models. It allows users to upload, annotate, and preprocess images, before exporting them in a format suitable for training. Roboflow supports a wide range of model architectures and frameworks, making it a versatile tool for computer vision projects. \cite{Roboflow}

\vspace{1em}

\noindent \textbf{DFL - Bundesliga Data Shootout Dataset} - Dataset created as part of the Bundesliga Data Shootout competiotion, organized by DFL in partnerhip with Amazon Web Services and Sportec Solutions AG. It consists of video clips from Bundesliga football matches, with the goal of providing a dataset for the development of innovative data-driven solutions for football analysis. \cite{DFL Bundesliga Data Shootout}

\vspace{1em}

\noindent \textbf{Football Data from Transfermarkt Dataset} - A clean and structured dataset containing football data from Transfermarkt, which is a well-known website featuring football statistics, market values, and transfers. It consists of \(60{,}000+\) games from various seasons across all major competitions, \(400+\) clubs from those competitions, \(30{,}000+\) players from those clubs, \(400{,}000+\) historical records of player market valuations, and \(1{,}200{,}000+\) player appearance records from all games.\cite{Davidcariboo}

\section{System Architecture}
The project of an application for Analysis of Football using Computer Vision consists of three main components (Figure 3). The frontend and backend module are responsible for the user interface and communication with the database and lets users interact with the system. It takes the user's input in the form of a video. The dashboard module is designed to display player statistics and information, while the video analysis module processes football clips to extract insights and key findings.\vspace{0.5em}
The main part of the application - the video analysis module - is responsible for processing football clips and extracting valuable insights. It processes the received video clip, indentifies key components then stores the data, which is later utilized to showcase the results to the user. The player statistics database is used to store and retrieve player information and statistics, which are displayed in the dashboard module. The communication between the modules is facilitated by the frontend and backend module, which acts as an intermediary, ensuring seamless data flow between the components.

\section{Modules Design} 
The application is composed of three components modules. Frontent Module, Dashboard Module, Video Analysis Module.
\subsection{Frontend and Backend Module}
The Frontend Module includes the User Interface, which has two separate tabs. One of them leads to the Video Analysis Module, where the user can upload a video for analysis. The other tab leads to the Player Statistics Dashboard, where users can search for a player and view detailed statistics. 
\subsection{Dashboard Module}
The Dashboard Module is responsible for displaying player statistics and information. It retrieves data from the Player Statistics Database and presents it in a user-friendly format. The dashboard allows users to search for specific players and filter the data based on various criteria, providing a comprehensive overview of the player's performance.
\subsection{Video Analysis Module}
The Video Analysis Module processes football clips to extract valuable insights and key findings. It uses computer vision algorithms to identify and track key components in the video, such as players, balls, goalposts, and referees. The module analyzes the video clip and stores the extracted data, which is later used to generate insights and statistics. The Video Analysis Module is the core component of the application, providing users with detailed match analysis and player performance metrics.
\section{Communication}
The communication between the modules within our application is essential for delivering real-time and accurate data across the frontend, Player Statistics Database, and video analysis sections. Each module has a distinct responsibility, but they work together seamlessly to create an integrated user experience.

\subsection{Frontend and Backend Communication}
The Frontend and Backend communicate through RESTful APIs to handle requests from both the Dashboard and Video Analysis modules. These APIs serve as intermediaries, allowing the frontend to request player statistics data or initiate video analysis processes.
\subsection{Video Analysis Communication}

The Video Analysis Module is a core part of the application and requires complex communication between the frontend, backend, and processing components to deliver accurate insights. When a user uploads a video via the frontend, it is sent to the backend server through an API request, where the video is securely stored temporarily, initiating the video processing pipeline. The processed data is sequentially communicated to ensure synchronization and accuracy, with intermediate results stored as they are extracted and structured. The backend utilizes this structured data to build a comprehensive report, which is stored in a dedicated database optimized for analysis results. Once the video analysis completes, the backend notifies the frontend with a summary and updates the user interface, indicating that the analysis results are ready for viewing. Users can then access these insights and metrics generated from the processed video in the Video Analysis section.


\subsection{Player Statistics Database Communication}

The Player Statistics Database is a critical component for displaying player data in the Dashboard Module. The SQLite3 database holds detailed player performance data, including historical performance metrics, recent game statistics, and player profiles. When a user performs a search or filter action on the frontend, the request is sent to the backend, which queries the SQLite3 database. The backend retrieves the relevant records based on search criteria and formats them for frontend display. The backend sends the requested player data to the frontend to be displayed on the Player Statistics Dashboard. This includes real-time updates, ensuring the user has access to the latest player performance metrics.

\section{Technology Selection}
This section provides a comprehensive overview of the technology stack utilized in developing the application.
\subsection{Python}
Python was selected as the primary programming language for this application due to its extensive ecosystem of robust libraries, which provide essential features for various aspects of development. Python's vast library support includes specialized packages for graphical user interface (GUI) design, database management, machine learning, and computer vision, all of which are integral to the application. Detailed descriptions of the libraries utilized to create the application can be found in the subsections below.

\subsection{Tkinter}
Tkinter is Python’s standard library for creating window-based applications, providing essential widgets like labels, buttons, and text fields \cite{Tkinter}. Its built-in status in Python and cross-platform support make it a convenient choice for developing straightforward desktop interfaces. In this project, Tkinter enables rapid prototyping and a consistent user experience across operating systems.

\subsection{CustomTkinter}

CustomTkinter extends Tkinter’s capabilities by adding modern, customizable widgets such as themed buttons and sliders, along with options like dark mode \cite{CustomTkinter}. This enhances the visual appeal and usability of Tkinter applications, providing a more professional interface. In this project, CustomTkinter is used to improve the user interface, combining Tkinter’s stability with an updated look and feel for better engagement.

\subsection{SQLite3}
SQLite3 is a lightweight, integrated library in Python designed for efficient management and interaction with SQLite databases. The primary advantage of SQLite databases lies in their self-contained, serverless architecture, requiring minimal configuration, which makes them exceptionally suited for local data storage. Additionally, SQLite allows accessing the database using a nonstandard variant of the SQL query language.\cite{SQLite3} Given these characteristics, SQLite3 is an optimal choice for this application, enabling streamlined access to the data. In this project, all CSV files  will be systematically stored in the database, facilitating more organized and efficient data retrieval and manipulation from the Transfermarkt dataset \cite{Davidcariboo}. 

\subsection{OpenCV}

OpenCV (Open Source Computer Vision Library) is an open-source computer vision and machine learning library designed to accelerate the use of machine perception in commercial products \cite{OpenCV}. It provides more than 2500 optimized algorithms for various computer vision tasks such as image processing, object detection, and image recognition. OpenCV is cross-platform and supports multiple programming languages, including Python, making it a versatile tool for computer vision projects.\vspace{0.5em}

\noindent In this project, OpenCV is utilized for processing the football match footage by performing essential image processing tasks such as reading video files, frame extraction, and image preprocessing. It works in conjunction with the YOLO algorithm to enhance object detection and tracking of players, balls, goalposts, and referees in the video clips. OpenCV's efficient image processing capabilities are crucial for preparing the video data for analysis and ensuring accurate detection results.

\subsection{YOLO}

YOLO (You Only Look Once) is a real-time object detection algorithm that frames detection as a single regression problem, predicting bounding boxes and class probabilities directly from full images \cite{Yolo}. Known for its speed and accuracy, YOLO can process images at high frame rates while maintaining high detection precision, making it ideal for real-time applications.\vspace{0.5em}

\noindent In this project, YOLO is employed to detect and classify key components within the football match footage, including players, balls, goalposts, and referees. By integrating YOLO into the video analysis module, the application can accurately identify and track these elements throughout the video clips. This facilitates the extraction of comprehensive statistics and insights about the match and player performances. The use of YOLO enables efficient processing of the video data, allowing for real-time or near-real-time analysis results.

\subsection{Roboflow}

Roboflow is a tool designed to streamline the process of building computer vision models by simplifying dataset management, annotation, and preprocessing \cite{Roboflow}. It provides an end-to-end solution for preparing image datasets, generating augmented data, and exporting them in formats compatible with various machine learning frameworks.\vspace{0.5em}

\noindent In this project, Roboflow is utilized to manage and preprocess the dataset used for training and fine-tuning the YOLO model. By leveraging Roboflow, we can efficiently annotate the football match images and videos, apply data augmentation techniques, and prepare the dataset in a format optimized for the YOLO algorithm. This enhances the quality of the training data, leading to improved model accuracy in detecting and classifying objects within the football footage. Roboflow's user-friendly interface and preprocessing capabilities significantly reduce the time and effort required for dataset preparation.
